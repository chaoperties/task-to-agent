## ลำดับการทำงาน

ใส่เมื่อมี job, transaction, การเปลี่ยน state, การเขียนลงระบบอื่น หรือคำขอที่มาพร้อมกัน
บอกจุดที่กันการทำซ้ำ และผลเมื่อแต่ละขั้นล้ม

```text

```

| ขั้น | ล้มแล้วเป็นอย่างไร | retry แล้วได้อะไร |
